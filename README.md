# fieldglass

A toolbox of instruments built on the sensors already inside an Android phone: magnetometer,
metal detector, level, compass, sound and light meters, and more. It's meant for hobbyists and
field researchers who don't have dedicated equipment, and it's partly an experiment in how far
phone sensors can go.

Phone sensors vary between models and none of them are calibrated instruments. fieldglass shows
you what your hardware reports and lets you record it, but treat readings as indicative.

## Status

Phase 1 (native sensors). On the phone, readings come from Android's sensors through a native
plugin. In a desktop browser the same screens run on a simulator, and a yellow "Simulated data"
badge says so.

Tools so far:

- **Sensor info**: every sensor the phone reports, with specs, live values, and a CSV export of
  the list.
- **Magnetometer**: total field and X/Y/Z, with recording and CSV export.

## Stack

- [Capacitor](https://capacitorjs.com) packages the app for Android.
- [Svelte 5](https://svelte.dev) + TypeScript for the UI, built with [Vite](https://vite.dev).
- Sensor access, signal processing and recording live in plain TypeScript under `src/core/`,
  independent of the UI framework.

## Layout

```
src/
  core/          plain TypeScript, no UI code
    sensors/     SensorSource interface, SensorHub, simulator
    processing/  math on readings
    recording/   Recorder and CSV export
    platform/    device helpers (keep screen awake)
  ui/            shared Svelte components and design tokens (tokens.css)
  tools/         one folder per tool
  app/           shell, routing, tool registry (tools.ts)
android/         native Android project (generated by Capacitor, committed)
  app/src/main/java/io/fieldglass/app/sensors/SensorsPlugin.kt
                 native plugin streaming Android sensor readings to the web layer
assets/          source images for launcher icons
```

To add a tool, create `src/tools/<id>/` and register it in `src/app/tools.ts`.

## Development

Requires Node 22+.

```sh
npm install
npm run dev        # open the printed URL in a desktop browser
```

The browser runs everything on simulated sensors. Other scripts:

| Script           | What it does                             |
| ---------------- | ---------------------------------------- |
| `npm run check`  | Typecheck TypeScript and Svelte          |
| `npm run lint`   | ESLint and Prettier                      |
| `npm run format` | Apply Prettier formatting                |
| `npm test`       | Unit tests (Vitest)                      |
| `npm run build`  | Production web build into `dist/`        |
| `npm run icons`  | Regenerate launcher icons from `assets/` |

## Running on a phone

One-time setup:

1. Install [Android Studio](https://developer.android.com/studio). It brings the Android SDK and
   a JDK.
2. On the phone, enable **Developer options** (Settings → About phone → tap Build number seven
   times), then turn on **USB debugging** under Settings → System → Developer options.
3. Connect the phone by USB and accept the debugging prompt.

Then:

```sh
npm run android    # builds, syncs into android/, installs and launches on the phone
```

`npm run android:open` opens the project in Android Studio instead, which is handy for logs
(Logcat) and debugging native code.

For live reload while editing, run `npm run dev`, then
`npx cap run android --live-reload --host <your computer's LAN IP> --port 5173`.

### Without Android Studio

Every push builds a debug APK in GitHub Actions. Open the workflow run under the repository's
**Actions** tab, download the `fieldglass-debug-apk` artifact, and install it on the phone
(you'll need to allow installs from that source).
